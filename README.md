# Projeto Noiva

App web de acompanhamento de treino. Instale no iPhone pelo Safari: Compartilhar → Adicionar à Tela de Início.
Funciona offline e guarda os registros só no aparelho (use o backup em Progresso).
Quando houver versão nova, o app mostra a faixa "Nova versão do app disponível": é só tocar em Atualizar.
